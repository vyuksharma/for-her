# Pallavi's Message Scrapbook Website

## Complete Google AI Studio Build Brief

Build a polished, mobile-first interactive scrapbook website for
Pallavi. This is a personal message website to accompany a physical gift
box containing KitKats, cutout prints, and a chocolate bouquet.

The website should feel personal, warm, playful, and emotionally honest.
It should not look like a generic Valentine's Day template or a birthday
invitation.

------------------------------------------------------------------------

# 1. Core concept

**Working title:** The Month Between Us

**Subtitle:** A little scrapbook made for Pallavi.

The story moves from a playful message about the chocolate box into a
sincere apology, then leaves room for additional message pages and a
final surprise.

Important context: - Lakshya and Pallavi are meeting again after about a
month apart. - Pallavi had been unwell. - The physical gift box has tiny
message slips attached to KitKats, along with cutout prints and a
chocolate bouquet. - The gift was paid for with Lakshya's own earned
money. - The website accompanies the physical gift; it should not
compete with it. - Do not invent shared memories, dates, photos, events,
or private details.

# 2. Visual direction

Use a premium scrapbook aesthetic: - Warm cream paper backgrounds. -
Blush pink, muted rose, soft mocha, and sage accents. - Torn-paper
edges, subtle paper grain, washi tape, little stickers, and layered
paper cards. - Polaroid-style frames where photographs are later
supplied. - Handwritten-style headings, but highly readable body text. -
Small panda illustrations and subtle chocolate/KitKat-inspired
decorative elements. - Gentle page transitions, paper-flip effects, and
restrained floating decorations.

Suggested palette: - Blush: `#F8E9E8` - Cream: `#FFF7EB` - Muted rose:
`#C98D9D` - Mocha: `#8C7771` - Sage: `#B9C9B0` - Dark text: `#59484A`

Avoid: - Excessive hearts on every screen. - Loud gradients, neon
colours, or childish UI. - Overly dramatic animations during the apology
page. - Making the website look like a shop, invitation, or public
social-media template.

# 3. Website structure and navigation

Create a multi-page experience. Show only one message page at a time.

Required behaviour: 1. Start with a welcome/envelope screen. 2. The
envelope has an **Open this little scrapbook** button. 3. Open Page 1
after the envelope interaction. 4. Add a visible **Next →** button at
the bottom of each message page. 5. Add a **← Previous** button on pages
after the first message page. 6. Show a small page counter, for example
`01 / 02`, updating automatically. 7. Use smooth, accessible transitions
without reloading the page. 8. Keep message content in a clearly
separated data structure so more pages can be added later. 9. Do not
show all message pages at once. 10. Do not invent the future pages or
write filler content for them. Build the structure so more pages can be
added when supplied. 11. The final page will eventually have a special
surprise and should not show a Next button. Do not decide which current
page is the final page because more messages are coming. 12. Make all
buttons functional. No decorative button should pretend to work.

# 4. Welcome screen copy

Heading: **Heyyyyy, you. ❤️**

Body: I made a little something for you. It's not a birthday gift, not
an occasion gift. I just had something to tell you.

Button: **Open this little scrapbook 💌**

# 5. Page 1 --- The chocolate confession

Page label: **A little message for Pallavi**

Heading: **Heyyyyy! ❤️**

Use the following message exactly as written. Preserve the line breaks,
expressive spelling, jokes, and emojis. Do not rewrite, summarize, or
remove any sentence.

------------------------------------------------------------------------

Heyyyyy! ❤️

So, you finally got the chocolate box I prepared for you!

Honestly, I can't tell you how happy I am after seeing you. It genuinely
feels like a dream. We used to see each other daily, hug and kiss each
other, and suddenly there was this whole month without meeting.

Last month was scary as fuck...

Wait... fuck is scary? 😭

Whatever.

Before you start regretting that I spent money on you, let me tell you
one thing.

I WANT to give you something using my own money.

There's a friend of mine for whom I prepared a proposal website, and I
charged him ₹500 for it. So yes, the money was earned by your Capy.

And all these cutout prints, KitKats and the bouquet? I bought them with
my own money too.

Yeahhhh, it's from your Capy's money. 😂

So don't be pressurized. Think of it as your future sugar daddy buying
things for you. 😭❤️

And that's exactly why I said this box is filled with love.

Now, if you feel burdened and want to thank me, there's just one tiny
thing you can do...

Send me a random, playful picture of my gudiya.

Because she looks SO CUTE. LIKE OH MY GOD, ITNI CUTEEEEEE. 😭❤️

WAITTTT...

I NEEEEED TO SEEEE MY GUDIYA'S PICCCCC.

BYEEEEEEEE!!!!! 🏃‍♂️💗

------------------------------------------------------------------------

Page 1 visual treatment: - Keep this page playful, energetic, and
cute. - Add a small panda/chocolate illustration, but don't let it
obstruct the message. - Break the message into readable paragraphs or
scrapbook note cards. - Emphasize the funny lines with slightly larger
handwritten-style text. - Keep the entire message accessible by
scrolling within the page if needed. - Include a clear **Next →** button
after the message.

# 6. Page 2 --- Something I needed to say

Page label: **A quieter chapter**

Heading: **Something I needed to say...**

Use the following message exactly as written. Preserve the line breaks
and emotional tone. Do not turn it into a poem, shorten it, or add
dramatic guilt-inducing language.

------------------------------------------------------------------------

Hey...

There's something else I want to tell you.

I'm not shameless enough to hurt you and then act like nothing happened,
being all lovey-dovey as if I did nothing wrong.

I'm genuinely ashamed of the mistakes I've made.

Sometimes, I think I'm doing something good for you, but in reality, I
end up hurting you. And maybe that's why it hurts me so much too.

I remember once saying to God that if I ever hurt you, let me feel 10
times the pain you felt.

I don't know how to explain everything, but I really wish I had
understood certain things earlier.

I know I've made mistakes. I won't deny them or make excuses for them.
But making mistakes doesn't mean I don't love you.

I love you so much. Itna ki kabhi-kabhi pyaar-pyaar mein tera achha
karne jaata hoon aur tujhe hi hurt kar deta hoon.

And I hate that.

I know you probably want to forget what happened. Maybe accepting my
apology isn't easy, and I understand that. You don't have to pretend
everything is okay just because I'm sorry.

But I still wanted to tell you this one more time.

I'm genuinely sorry, Pallavi.

I'll work on understanding you better instead of assuming that whatever
I think is good for you will actually be good for you.

And this is the last time I'll bring this up. I don't want to keep
making you revisit something that has already hurt you. I just hope
things stay healthy, peaceful and happy between us.

Thank you for staying till the end and reading all of this.

And once again...

I'm heartily sorry. ❤️

------------------------------------------------------------------------

Page 2 visual treatment: - Make this page noticeably calmer than
Page 1. - Use warm cream paper, subtle pressed-flower details, and muted
rose accents. - Use gentle fade-in or line-by-line text reveal. - Do not
use bouncing elements, loud effects, or joke stickers on this page. -
Keep the text readable and give it breathing room. - Include **←
Previous** and **Next →** navigation. - Do not add guilt-inducing copy
or imply that Pallavi must forgive, reply, or comfort Lakshya.

# 7. Additional pages and final surprise

More message pages will be supplied later. For now: - Build a reusable
page component and message data structure. - Make it easy to add Page 3,
Page 4, and further pages without rewriting navigation. - Do not
generate the content of future pages. - Do not make Page 2 the final
page. - Reserve a configurable final-page state for a future surprise. -
The final surprise should only be implemented after its exact content is
provided.

# 8. Technical and accessibility requirements

-   Mobile-first and responsive, especially for Android phone screens.
-   Use a clean, maintainable component structure.
-   Keep page content separate from layout and styling.
-   Use reliable local assets or simple CSS decorations; do not depend
    on broken external image URLs.
-   If using images, make them responsive and provide appropriate alt
    text.
-   Respect reduced-motion preferences where possible.
-   Ensure good contrast and comfortable font sizes.
-   Prevent text from overflowing or being clipped.
-   Keep navigation buttons large enough to tap.
-   Make the page counter reflect the current page.
-   Ensure browser back/forward behaviour is sensible if practical.
-   Do not add login, payments, databases, analytics, or cloud storage.
    This is a simple personal message website.
-   Do not remove or replace any existing project features if this brief
    is being added to an existing project. Preserve the current code and
    functionality; make only the changes needed for this scrapbook.

# 9. Build order

First, build: 1. The welcome/envelope screen. 2. Page 1 with the
complete chocolate confession. 3. Page 2 with the complete apology. 4.
Working Previous/Next navigation and page counter. 5. The visual style
and responsive layout.

Then test: - Opening the envelope works. - Next moves from Page 1 to
Page 2. - Previous returns from Page 2 to Page 1. - The page counter
updates correctly. - All message text is present and unchanged. - The
site works on a narrow mobile screen. - No buttons are inert.

Do not add invented content. Leave the structure ready for the next
message pages that will be provided separately.
